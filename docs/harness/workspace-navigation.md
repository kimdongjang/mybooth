# 개인 홈·재고·행사 화면 계약

2026-10-27 PR 코드 기준. 기존 제작자·행사 권한과 판매·정산 API의 범위를 유지한다.

## 개인 메뉴와 화면

- 상위 메뉴는 대시보드·행사 선택·내 재고관리·마이페이지다. 수익현황은 마이페이지 내부의 별도 `/account/revenue` 화면이며 기존 `/revenue` 링크도 지원한다.
- 대시보드는 확인 필요 항목·참여 행사·내 재고·내 정산을 데스크톱 동일 너비 2열, 모바일 1열로 표시한다. 확인 항목이 없으면 숨기고 지난 행사는 접는다. 예상/확정 정산을 구분하고, 기간 필터는 내 판매액에만 적용한다.
- 재고 하위 메뉴는 내 재고관리·재고 일괄등록·내 판매내역 순이다. `/inventory/sales`와 이전 `/inventory/movements`는 판매내역 화면을 표시하며 개인 로스 입력 화면은 제거했다. 기존 차감 원장과 행사 내부 로스 계약은 보존한다.
- 내 판매내역은 `artists=history`의 본인 귀속 행사 상품·수량·금액·취소 상태만 표시한다. 검색·상세 조건·열 정렬을 제공한다. 온라인 판매 입력은 상품/판매일/수량/총금액/선택 메모 팝업 UI까지이며 저장 버튼은 비활성이다. 저장·재고 차감·취소·수익 반영 API는 후속이다.

## 행사 정보와 선택

- 행사 위치는 별도 `pos_event_details(project_id, venue)`에 보존한다. 기존 프로젝트 행을 변경하지 않아 이관 원본 지문을 유지한다. 계정/프로젝트 삭제와 참조 관계는 외래 키로 유지한다.
- 생성과 구성 가져오기 UI는 행사명·위치·시작일·종료일을 입력받는다. API는 기존 이름만 보내는 호출도 허용한다. 위치는 200자 이내 문자열, 날짜는 유효한 날짜이며 시작일≤종료일이어야 한다. 일정은 기존 `pos_event_stock_policy`를 재사용하므로 행사 기간 재고 수정 정책에도 반영된다.
- 생성과 장소/일정 저장은 같은 트랜잭션이다. 구성 가져오기는 장소·기간을 요청 지문에 포함하며 같은 ID/같은 내용은 기존 결과, 같은 ID/다른 내용은 409다. 행사 정보 수정의 기존 운영 권한·비밀번호 검증을 유지한다.
- 백업/복원과 구성 가져오기는 `project.venue`를 보존한다. 기존 백업의 위치 생략은 빈 값으로 취급한다. 행사 목록은 기존 권한 범위 안에서 위치·일정을 함께 반환한다.
- 행사 선택은 가장 가까운 예정 행사를 시작일순으로 먼저 표시하고 진행 중·일정 미설정·종료/보관 순으로 이어진다. 과거 행사는 최근 종료일 우선이다. 한국 날짜 기준 상태와 디데이를 표시하고 행사명 옆에 짧은 기간을 표시한다. 일정 없는 행사는 추정하지 않는다.
- 행사 등록은 상단 행사 선택·새 행사 추가 탭을 사용한다. 관리 가능한 행사의 더보기는 명시적 projectId를 가진 행사 관리 링크와 구성 가져오기 버튼을 제공한다.

## 공통 표현과 실행 경계

탭은 구매 방식과 동일한 글꼴·높이·선택 밑줄을 재사용한다. 모바일 상위 메뉴는 항목마다 한 줄로 배치한다. 재고·등록·판매내역은 1120px, 행사 판매현황은 1440px, POS 판매 목록은 최대 너비 제한 없이 표시한다. 화면 표현 수정은 공통 폰트·테이블 헤더 가운데 정렬을 유지한다.

운영 DB 적용·배포와 브라우저/모바일 실기기 확인은 로컬 테스트와 별개다. 온라인 판매 입력은 아직 저장하지 않는다.
