# 06 — 구형 계약 정리

상태: 로컬 구현·격리 검증 및 기존 admin 부스의 실제 종료 적용/보존 대조 완료. 활성 저장 열·별칭의 물리 제거는 미완료다. 05 기업 모드는 사용자 지침으로 제외한다.

[진행 현황](README.md) · [공통 계약·검증](common-contracts-and-validation.md)

## 시작 조건

01~04의 현재 계약을 유지한다. 서비스가 운영 전이므로 운영 중 관찰 기간을 임의로 채우지 않는다. 기존 실제 행사 자료·기기별 미전송 주문·백업을 확인한 후 부스별로 구형 쓰기를 종료한다. 로컬 구현 완료와 실제 DB 전환은 구분한다.

## 완료 조건

로컬 범위는 종료·복구 API/UI와 ID 기반 신규 요청 및 데이터 보존 검증이다. 전체 저장 형식의 교체/물리 삭제까지 완료한 것으로 취급하지 않는다. 실제 DB 적용·실 PostgreSQL 경쟁·다기기/브라우저·Android·배포 검증은 별도다.

## 작업 결과 기록

변경 파일·검증·남은 참조와 적용 절차는 [06 구현 결과](06-implementation.md)를 따른다. 커밋·푸시·PR·배포 없이 로컬 작업만 수행했다.
