# 작가 중심 작업 공간 구현 상태 (2026-10-23)

대시보드 / 행사 선택 / 재고관리 / 내 수익현황 / 마이페이지로 메뉴를 재배치했다. 재고는 내 작가 프로필을 기본으로 조회하며 운영자는 참여 작가를 선택해 대리 관리한다. 부스 정보와 공통 멤버 관리는 행사 선택 화면에서 진입한다.

행사 참여 작가는 자신의 판매·정산만 조회한다. 판매 담당자와 부관리자는 행사별로 지정하며 서버에서도 권한을 검사한다. 행사 당일 작가의 행사 재고 변경은 차단하고 운영자·권한을 받은 부관리자가 관리한다. 작가 계정이 없는 기존 프로필은 초대 코드로 나중에 연결하며 이름만으로 연결하지 않는다.

기존 저장 구조와 새 물리 테이블명을 모두 읽는 어댑터, 백업·격리 리허설·원본 대조·전환 스크립트를 추가했다. 실제 DB 테이블 교체는 실행하지 않았다. 과거 내부 필드명과 판매 스냅샷의 호환 경계는 유지한다.

## 검증 및 승인 대기

- 빌드와 행사별 권한·납품 없는 재고 배정·계정 연결·전환 및 롤백 관련 개별 자동 검증을 수행했다.
- PR 분리 후 최종 전체 테스트 재실행은 대기 중이다. 이전 분리 실행의 화면 테스트 불일치는 기존 main 테스트로 복원했으며 최종 통과로 단정하지 않는다.
- 실제 브라우저·다기기 오프라인·실 PostgreSQL 동시성 검증은 미실행이다.
- 앞서 반영된 배포는 이전 운영 버전으로 롤백했다. 이후 배포와 실제 DB 전환은 PR 승인 후 진행한다.
- 소유자가 확인되지 않은 기존 상품은 그대로 보존하며 실제 작가 확인이 필요하다. 기업 모드는 이번 범위에서 제외한다.
