### 4.2 스키마·권한 기반

- [x] 새 테이블·nullable 참조를 먼저 추가하는 확장 마이그레이션을 작성한다. 초기 단계에서 기존 열·복합 키를 제거하지 않는다.
- [x] 안정적인 ownerId / artistId / boothId / recipientId와 기존 ID 매핑을 정의한다. 표시명 변경이 식별자를 바꾸지 않게 한다.
- [x] 부스 멤버십과 자원 소유권을 확인하는 서버 공통 권한 함수를 추가한다. 요청의 boothId/ownerId를 신뢰하지 않는다.
- [x] 행사↔부스·원본 재고↔소유자·상품↔수취인을 FK/서버 권한으로 보장한다. 신규 납품 항목의 FK는 해당 기능을 구현하는 04 범위로 둔다.
- [x] 모든 조회·쓰기·CSV·이미지·백업 경로를 점검한다. 02의 소유자 재고 조회는 수량 요약만 서버에서 반환한다. 작가 판매·정산 조회 UI/조회 계약은 03이며 현재 활성화하지 않는다.
- [x] 서로 다른 사용자가 같은 부스를 수정할 수 있으므로 기존 계정 잠금을 자원/부스/행사 잠금으로 재설계하고 잠금 순서를 고정한다.
- [x] 요청 ID의 유일 범위와 payload fingerprint를 정한다. 재전송·다중 연결 경쟁에서 영수증과 실제 변경을 원자적으로 저장한다.

### 4.3 기존 데이터 이전

- [x] 기존 계정마다 기본 부스를 만들고 기존 사용자를 소유자로 연결한다. 기존 행사 ID는 유지한다.
- [x] 계정 내부의 제작자 표기별 미연동 프로필 후보를 만든다. 동명이인·빈 이름·여러 표기·세트 제작자 예외 목록을 생성한다.
- [x] 제작자 표기는 소유권 확정의 근거가 아니므로 자동 매핑은 임시 분류로 한정하고 운영자 확인이 필요한 항목을 표시한다.
- [x] 다른 계정의 같은 이름은 자동 병합하지 않는다. 상품 코드/이름이 같아도 상품과 거래를 삭제·중복 제거하지 않는다.
- [x] 기존 창고/배정·판매·로스·과거 차감을 초기 위치 투영으로 보존하고 현재 수량은 원본 테이블에서 조회한다. 이미 행사에 있는 수량을 새 납품으로 다시 차감하지 않는다.
- [x] 행사 상품·세트 구성·판매 lines·취소·차감·부분 지급·지급 취소·마감 스냅샷·영수증을 매핑한다.
- [x] 과거 스냅샷은 원본을 보존하고 별도 매핑/버전으로 연결한다. 작가 ID 추가를 이유로 과거 매출·정산금을 재계산하지 않는다.
- [x] 새 참조가 없는 구형 데이터는 명시적 호환 읽기로 처리한다. 신규 데이터의 누락 참조를 무조건 구형 경로로 우회시키지 않는다.
- [x] 미연동 작가 재고는 기존 입력 흐름을 호환 처리하고 초기 이관에서 수량을 한 번만 반영한다. 신규 입고+납품의 단일 작업 기능은 04에서 구현한다.
- [x] 기존 부스 운영 화면을 유지한 상태로 새 권한/조회 계층을 연결한다.

완료 조건: 기존 부스 운영 흐름과 수량·판매·정산 합계가 보존되고, 부스 보관/계정 탈퇴로 작가 이력이 연쇄 삭제되지 않는다. 초대·작가 화면은 다음 단계여도 된다.

- 다음 작업의 시작점: 03의 작가 프로필 연결·초대 계약을 실제 이관된 owner/artist/recipient ID에 연결한다. 미지정 4개는 임의 계정에 연결하지 않고 해당 작가 확인 시 처리한다.
- 다음 단계 진입 가능 여부와 근거: 03 진입 가능. 사용자 확인으로 현재 서비스는 운영 전이며, 실제 7월/같은 계정 12월 자료의 백업·복사 DB 재현·실제 PostgreSQL 이관·커밋 후 대조까지 통과했다. 다중 사용자 공개 운영 준비 완료를 뜻하지 않는다.

## 미실행 검증의 영향

- [x] 현재 자료가 있는 실제 PostgreSQL에서 추가 DDL·이관·원본/타 계정 보존을 확인했다.
- [ ] 실제 PostgreSQL의 다중 연결 경쟁·교착/부하는 공개 운영 전 검증으로 남긴다. 실제 이관 성공을 경쟁 검증으로 대체하지 않는다.
- [ ] 브라우저/다기기에서 업그레이드·계정 전환·권한 회수·마감 이후 미전송 주문과 캐시를 확인한다.
- [x] 실제 기존 자료의 원본/연결·금액·수량을 백업/대조하고 이관했다. 미지정 상품 4개는 보존했으며 실제 계정 소유권은 03 연결 시 확인한다. 이관 전후 원본은 동일하다.
- [ ] 서버/웹/Android 배포와 CACHE-01을 확인한다. 배포 요청이나 운영 적용을 수행하지 않았다.

## 후속 실제 자료 이관 (2026-10-22)

사용자의 운영 전/실시간 변경 없음 설명과 이관 요청에 따라 실제 DB의 admin 자료를 이관했다. 7월 122건·2,913,000원과 같은 계정의 12월 자료, 공통 재고 46개와 모든 원본 지문을 보존했고 다른 계정 지문도 동일하다. 백업·복사 DB 이관/재실행·실제 이관·커밋 후 검증을 통과했다. 상세 경로·제한은 [이관 결과](02-data-migration.md)를 따른다. 앞의 운영 데이터 미적용 기록은 초기 구현 시점의 이력이다.
